# House Price Prediction Using Machine Learning

## Project Overview

This project predicts house prices using machine learning techniques based on various housing features such as location, income, number of rooms, population, and house age.

The goal is to build a regression model that can estimate the median house value accurately.

## Dataset

Dataset: California Housing Dataset

Features:

* Median Income
* Housing Median Age
* Total Rooms
* Total Bedrooms
* Population
* Households
* Latitude
* Longitude

Target Variable:

* Median House Value
